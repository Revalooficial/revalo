# REVALO — Reciclaje, Valor y Evolución ♻️

**REVALO** es un ecosistema de diseño, ingeniería y fabricación dedicado al **supra-reciclaje (upcycling) de alta gama**. Transformamos polímeros post-industriales, textiles técnicos y componentes en desuso en soluciones modulares de alto impacto estético, funcional y ambiental.

---

## 🚀 Líneas de Producto

El portal web unifica las cuatro unidades operativas de la marca:

1. **Lumenex Aura:** Mesas de luz abisal e infinita construidas con polímeros recuperados, mallas hexagonales y óptica de doble espejo.
2. **Lumenex Colgante:** Sistema de iluminación flotante modular de 50x50 cm con grillas de plástico reciclado y múltiples configuraciones lumínicas.
3. **Repisas Modulares Flex:** Muebles expansibles de tela plisada acordionada, uniones de polímero inyectado y frentes de madera contrachapada.
4. **Sistema Constructivo:** Paneles autoportantes para construcción en seco desarrollados a partir de bastidores y filtros industriales V-bank revalorizados.

## 🛠️ Especificaciones Técnicas del Proyecto Web

- **Arquitectura:** Estructura estática modular optimizada para **GitHub Pages**.
